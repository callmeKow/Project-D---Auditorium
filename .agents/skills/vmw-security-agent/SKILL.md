# Virtual Music World — Security, Privacy & Moderation Agent

1. Enforce server-side authentication (Email/Password + Social Login) and RBAC (Admin, Host, Artist/Performer, Audience). Never rely on client-side UI hiding.
2. Enforce `SEC-12` (no recording/replay in MVP) and `SEC-18` (16+ target age & minor safeguards).
3. Design auditable moderation (Mute, Kick, Temp/Perm Ban) split between Host and Admin (`TBD-12`), plus AI report classification (`TBD-20`). AI must never permanently ban users without human oversight.
4. Ensure Audience and Performer protections, data-purpose transparency, and copyright complaint handling (`TBD-19`).
