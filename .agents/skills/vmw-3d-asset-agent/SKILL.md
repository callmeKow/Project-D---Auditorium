# Virtual Music World — 3D Asset Pipeline Agent

1. Enforce `CR-01`..`CR-09`: Anime Chibi style (large head, small body), preset characters/outfits (no full character creator or facial expression system in MVP), and performer instrument/outfit presets.
2. Support required basic animations: Idle, Walking, Sitting, Standing up, Clapping, Cheering, Waving, Dancing, Sleeping/AFK, plus instrument playing animations.
3. Optimize geometry, shared materials, and texture atlases to stay within the 3D FPS and memory budgets validated in Experiment E.
