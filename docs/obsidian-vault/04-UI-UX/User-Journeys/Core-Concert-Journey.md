# Core Concert User Journey (`CONFIRMED` Flow)

```text
Landing Page -> Explore Concerts -> Select Concert -> 2D Seat Selection -> Enter 3D Auditorium
```

## End-to-End Steps (Blueprint Section 2)
1. User signs in (Email/Password or Social Login).
2. User discovers a concert (List, Calendar, Search, Featured).
3. User selects a seat using a **2D Seat Map** before entering the 3D room.
4. User enters a 3D **Small Room** as a preset Anime Chibi avatar (restricted to aisles/seating).
5. Performer configures audio devices and completes **Sound Check**.
6. Performer starts a live or prerecorded performance.
7. Audience receives continuous audio and synchronized 3D presentation.
8. Audience uses collapsible text chat and reactions without disrupting the concert.
9. Setlist and lighting cues progress through the show.
10. Concert ends and users can discover another concert.
