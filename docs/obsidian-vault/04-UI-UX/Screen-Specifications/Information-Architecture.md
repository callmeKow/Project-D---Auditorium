# Information Architecture & UI Principles (`PROPOSED`)

## Proposed Main Routes / Screens
```text
/
├── Landing
├── Explore (Concert List, Calendar, Search, Featured)
├── Concert Detail
├── Seat Selection (2D Map)
├── Lobby (Minimal)
├── Auditorium (Stage View, Collapsible Chat, Audience Controls, Role-gated Performer Controls)
├── Create Room / Create Event
├── Performer Setup (Device Selection, Input Config, Sound Check, Setlist)
├── Profile / Avatar (Chibi Presets)
└── Admin / Host Console
```

## UI Principles (`CONFIRMED`)
- **Outside Auditorium:** Discovery can be information-rich; professional music-platform aesthetic.
- **Inside Auditorium:** Minimal UI; stage and avatars take priority.
- **Chat:** Collapsible/hideable livestream-style text panel.
- **Seating:** 2D seat selection occurs before entering the 3D room.
- **Performer Setup:** Dedicated workflow (not hidden settings).
