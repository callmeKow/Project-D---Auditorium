# Release Checklist, DoR & DoD

## Definition of Ready (DoR)
A task is ready only when:
- [ ] Linked to approved requirement IDs (`PR-*`..`ST-*`)
- [ ] Clear objective, explicit scope, and explicit non-goals
- [ ] Dependencies known & API/data contracts agreed
- [ ] Acceptance criteria are testable
- [ ] Required design assets/references available
- [ ] Human approval requirements identified

## Definition of Done (DoD)
A task is done only when:
- [ ] Meets acceptance criteria & relevant tests pass
- [ ] No critical regression; authorization & error handling verified
- [ ] Performance implications checked where relevant
- [ ] Obsidian KB & requirement traceability updated
- [ ] Agent reports evidence & known limitations
- [ ] Human review complete where required

## Mandatory Launch Quality Gates (`ST-05`)
- [ ] Audio quality & continuity gate passed
- [ ] 3D FPS & device-tier gate passed
- [ ] Multiplayer stability & 100–500 CCU gate passed
- [ ] Security, privacy (16+), moderation & copyright gate passed
- [ ] Product Owner release approval obtained
